# Архив чатов текущего аккаунта

В боковом меню откройте «Архив чатов». «Обновить» ставит обнаружение и сохранение истории в очередь. Сначала сохраняется последняя страница всех доступных чатов, затем постепенно прежние сообщения. «Экспорт» скачивает ZIP выбранного чата или всего сохранённого аккаунта при поиске по архиву.

В существующих «Настройках» находится блок «Архив чатов» с общей кнопкой сохранения. Автосохранение, события и пять типов автозагрузки вложений изначально выключены.

| Параметр | Действие |
|---|---|
| Сохранять автоматически | Новые сообщения, обнаружение и постепенная история |
| Все/выбранные/исключённые | Область сбора; ранее сохранённые исключённые чаты остаются |
| Начальная дата | Пустая — вся доступная история; иначе нижняя граница сбора |
| Проверка 1/5/15 минут | Интервал после обнаружения; сеть и очередь добавляют время |
| События | Отдельная подписка на изменения/удаления; общая очередь пользователя хранится 24 часа |
| Изображения/документы/аудио/видео/прочие | Автозагрузка только выбранных типов |
| Также старая история | Постановка подходящих ранее обнаруженных файлов в очередь |
| Расписание файлов | Дни и часы компьютера; текст сохраняется вне окна |
| Лимит размера | 0 — без ограничения; ручное скачивание обходит лимит и расписание |
| Папка чатов | По умолчанию «Чаты» рядом с «Совещания»; автоматического переноса нет |

«Догрузить историю» продолжает текущий прогресс. «Сохранить период» задаёт даты и чаты; повтор дополняет архив и сверяет версии. Если чаты не выбраны, используется сохранённая область сбора. Сначала сохраните настройки, затем запускайте эти действия.

Если чат не обнаружен, добавьте `chat` + его ID, ID собеседника личного диалога либо ссылку подключённого портала с `IM_DIALOG`. Добавление проверяет доступ. Последние диалоги не гарантируют обнаружения всех скрытых чатов и веток.

Согласие на события относится к аккаунту. Если отслеживание включили до подключения, согласие применяется к первому подключённому аккаунту. Для другого аккаунта требуется выключить и заново включить переключатель, сохранив настройки; состояние согласия показано рядом с ним. Изменение папки архива того же аккаунта не требует нового согласия.

## Полнота и файлы

У чата видны охват, время проверки и ограничения. «Доступная история сохранена» означает достижение границы ответа источника для нижней даты. Удалённые до начала сбора сообщения, тарифно закрытая история и недоступные оригиналы могут отсутствовать. Исчезновение из выборки не считается удалением.

Структурированные ответы/пересылки сохраняют ID оригиналов. Отправитель отделён от автора оригинала. Цитата без подтверждённой связи не получает выдуманного автора. Дополнительный контекст не считается полной выгрузкой исходного чата. Время наблюдения редакции не выдаётся за время правки.

Файлы скачиваются по одному, с резервом 1 ГБ, проверкой размера и SHA-256. Временные ошибки повторяются; причины недоступности видны. Имена не перезаписывают содержимое другого ID. Переносимые файлы: `archive.json` → папка портала → `user-ID/account.json` → `chats/chat-ID/chat.json`; внутри `messages/YYYY-MM.md`/`.jsonl`, `versions/YYYY-MM.jsonl`, `context/excerpts.jsonl`, `attachments/file-ID/hash_имя`, `notes/`. Без даты — `undated.*`. Общая книжка — `_notebook`. Токены и служебные ссылки скачивания не экспортируются.

SQLite содержит индекс/очередь. Потерянный индекс восстанавливается из корректных файлов при выборе той же папки и аккаунта. Заметки и книжка не переписываются. Повреждённый JSONL остаётся на месте, а ошибка восстановления не означает пустого архива.

Для AI: [meeting-archive-files](../skills/meeting-archive-files/SKILL.md) и [режим чатов](../skills/meeting-archive-files/references/chats.md). Читайте выбранные месяцы Markdown, проверяйте связи/версии по JSONL. Прежние анализы совещаний не инвалидируются.

## Официальные источники

- [Поиск истории](https://apidocs.bitrix24.ru/api-reference/chats/messages/im-dialog-messages-search.html): страницы до 200, даты, контекст, тарифный признак.
- [Резервная история](https://apidocs.bitrix24.ru/api-reference/chats/messages/im-dialog-messages-get.html): до 50; удалённый курсор требует перепроверки границы.
- [События](https://apidocs.bitrix24.ru/api-reference/chat-bots/chat-bots-v2/im.v2/events/event-get.html): общая очередь и подтверждение после записи.
- [Файлы](https://apidocs.bitrix24.ru/api-reference/chat-bots/chat-bots-v2/im.v2/files/file-download.html): одноразовая ссылка перед скачиванием.

Нужно право `im` и доступ текущего пользователя. Разработка, документация и тесты используют только вымышленные данные. Реальный портал и его варианты ответов проверяет пользователь после обновления.
