# GigaAM v3: установка и ограничения

GigaAM — отдельный движок в локальном модуле Meeting Archive. Включён вариант `gigaam-v3-e2e-rnnt` для русской речи: веса около 449 МБ, дополнительные небольшие библиотеки и исходники устанавливаются отдельно. Общий Python/PyTorch используется вместе с Whisper; программы расшифровки на компьютере остаются независимыми.

## Установка через приложение

1. Откройте локальную расшифровку и список пакетов установки.
2. Отметьте GigaAM v3. При необходимости отметьте одновременно Parakeet и нужные модели Whisper. Выберите GPU либо подтвердите осознанную обработку на CPU.
3. Посмотрите оценку загрузки и свободного места. Подтвердите установку выбранных пакетов. Закреплённые исходники и веса загружаются только после этого выбора.
4. Дождитесь завершения установки. При отмене или ошибке повторите её: проверенные неизменённые веса сохраняются. Статус установки и ошибка доступны в очереди.
5. Выберите GigaAM как активный движок. Откройте сохранённую запись и выполните короткий тест, затем проверьте текст по аудио. Одно наличие файлов не доказывает качество распознавания.

## Что обозначают параметры

- `auto` и `ru` запускают русскую модель GigaAM. Она не определяет язык разговора; выбор `en` отклоняется с предложением другого движка. Для многоязычной записи выберите подходящую модель Whisper или Parakeet.
- Определение пауз использует собственный Silero VAD. Это не разделение говорящих. Оно не требует Hugging Face токена.
- Диаризация выполняется отдельным общим этапом pyannote после распознавания и требует подтверждённого доступа к её моделям. Локальные метки говорящих автоматически не превращаются в имена сотрудников.
- На GPU используется CUDA и float16 encoder, на явно выбранном CPU — float32. Ошибка GPU не переключает обработку на CPU.
- Таймкоды обозначают границы обработанных фрагментов аудио длиной до 25 секунд. Они не являются точным временем произнесения каждого слова. В JSON поле `words` пустое; вероятность языка не назначается (`null`). Длинные записи читаются небольшими окнами.

Такие таймкоды подходят для перехода к фрагменту записи и черновых субтитров. Перед публикацией субтитров или выводами о репликах отдельных говорящих проверьте границы по исходному аудио. Шум, перекрывающаяся речь и разрезание непрерывной реплики на фрагменты могут влиять на результат.

Установщик получает архив конкретного commit, проверяет SHA-256, извлекает только разрешённые Python-файлы и сохраняет лицензию. Веса, конфигурация и tokenizer проверяются по размеру и SHA-256. При распознавании исходники и модели проверяются повторно, сетевой загрузки нет. Код `modeling_gigaam.py` из Hugging Face не запускается; официальный фиксированный конфиг преобразуется в разрешённые классы GigaAM, а веса читаются через `torch.load(weights_only=True)`.

Служебная папка движка — `%LOCALAPPDATA%\MeetingArchive\module\engines\gigaam`. Небольшие зависимости устанавливаются в `addons`, исходники — в `packages`, веса — в `model`. Общая среда и найденные ресурсы другого приложения при добавлении движка не обновляются. Сам архив находится отдельно.
