# Устройство приложения

Базовый процесс Python/FastAPI запускает локальный интерфейс, каталог Bitrix24, сохраняемую SQLite-очередь и значок pystray. Все HTML/JS/CSS поставляются локально. Сервер слушает `127.0.0.1:8765`; изменяющие запросы требуют защитный токен и проверку источника. OAuth callback допускается только с ожидаемым одноразовым `state`.

Архив и служебное состояние разделены. `meeting.json` содержит перечень файлов и SHA-256; скачивание/копирование выполняется во временный файл, после проверки — атомарная замена. Идентичность Bitrix24 связывает портал, `callId` и UUID сессии, если доступен. Название не участвует в ключе.

Необязательный модуль устанавливается через закреплённый uv в `%LOCALAPPDATA%\MeetingArchive\module`. Базовая сборка и управляемый модуль используют Python 3.12.15. Python runtime, virtualenv, кэш установщика и модели располагаются внутри принадлежащей приложению папки. Удаление разрешено только после проверки точного пути, маркера владения и отсутствия внешних ссылок/junction. Базовая сборка не импортирует torch и модели.

Worker запускается отдельным Python. На stdin передаётся одно JSON-задание; stdout содержит строки JSON `progress`, `result`, `error`. Обычный вывод библиотек направляется на stderr. Отмена завершает дочерний процесс; результаты каждого запуска сохраняются отдельно. GPU-профиль использует torch/torchaudio 2.7.1+cu128, CPU — 2.7.1+cpu. Lock-файлы закрепляют все транзитивные версии и SHA-256.

Внешний адаптер указывает на папку существующего приложения с `src` и `.venv-gpu-ready`. Worker запускает его Python с `-B`, читает исходные модули и пишет только собственные выходные файлы. Исходная программа, её конфигурация и окружение не обновляются. Этот адаптер зависит от совместимости исходных интерфейсов и проверяется отдельно.

Секреты находятся в Windows DPAPI. Настройки и архив не включают OAuth-токены, client secret, Hugging Face-токен или webhook. Журналы и ошибки редактируются перед показом. Локальный архив остаётся приватным: публикация репозитория приложения не должна включать записи и тексты.
