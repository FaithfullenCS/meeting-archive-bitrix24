# Удаление программы и выбор компонентов

`uninstall.cmd` рядом с `MeetingArchive.exe` открывает окно Windows. Python и права администратора не нужны. Логика удаления находится в `scripts/reset-profile.ps1`, окно — в `scripts/uninstall-ui.ps1`.

По умолчанию отмечены программа и профиль. Совещания, чаты и модели сохраняются. Можно отдельно выбрать:

- программу и её регистрацию в Windows;
- настройки, локальные ключи, каталог, очередь и кэш;
- собственные модели и библиотеки Meeting Archive;
- текущий архив совещаний вместе с его заметками;
- текущий архив чатов вместе с вложениями и заметками.

1. Запустите `uninstall.cmd` и отметьте нужные компоненты. Для сброса настроек без удаления программы снимите «Программа».
2. Если приложение работает, нажмите «Завершить приложение». Оно штатно закрывается через защищённый локальный интерфейс и дожидается текущей записи. Принудительное завершение PID не используется. При ошибке выберите «Выход» в трее и повторите.
3. Нажмите «Проверить выбранное». Просмотрите точные пути, число файлов, объём и перечень сохраняемого.
4. Нажмите «Удалить выбранное» и подтвердите действие. Архивы удаляются только при отдельно отмеченном компоненте.
5. Прочитайте итоговый отчёт в этом же окне: что удалено, что сохранено, какие ошибки возникли. Частичное удаление не объявляется полным успехом.

Удаление нельзя отменить. Перед выбором архивов сохраните нужные материалы отдельно. Внешние оригиналы входящих записей, общие кэши, среды и модели других программ не удаляются. Сохранённые архивы и собственные модели остаются по прежним путям. После удаления профиля подключение и настройки задаются заново; старую папку чатов можно выбрать для восстановления её индекса из файлов.

Файлы программы удаляются по `update-manifest.json`, с проверкой SHA-256 и границ папки. Изменённые справки и посторонние файлы сохраняются. Если главный EXE изменён, удаление останавливается до первого изменения. Удаляются только совпадающие регистрации этой копии: новая копия в другой папке сохраняет свои записи Windows. Работающий экземпляр этой программы в другом профиле блокирует её удаление.

Архивы определяются из настроек и собственных манифестов. Скрипт не следует путям из содержимого `meeting.json`/`chat.json`; имя и расположение чата сверяются с идентичностью. Посторонние файлы рядом сохраняются. Неизвестные старые архивы в других местах не ищутся. Повреждённые настройки, пересекающиеся корни, корень диска, внешние ссылки и junction блокируют опасную операцию. Состав плана повторно проверяется перед удалением. Пустые родительские папки могут остаться.

Скрипт удаляет только локальные ключи: приложение на портале и токен Hugging Face отзываются владельцем отдельно. Значения ключей и подписанные адреса в отчёт не выводятся. Отчёт по умолчанию показывается в окне; файл создаётся только при явном `-ReportPath`.

## Командная строка и совместимость

Старые параметры поддерживаются: `-Mode Profile` сбрасывает профиль и сохраняет программу/архивы/модели; `-Mode All` дополнительно удаляет распознанные совещания, чаты и собственный модуль. `-Mode Custom` использует отдельные флаги `-RemoveProfile`, `-RemoveMeetings`, `-RemoveChats`, `-RemoveModels`, `-RemoveApplication`. `-Preview` не удаляет данные, в том числе в окне. `-CloseRunning` разрешает штатное завершение указанного профиля. `-ApplicationRoot` выбирает проверяемую копию программы; `-ProfileHome` — отдельный профиль. Если задан `MEETING_ARCHIVE_HOME`, он остаётся значением по умолчанию.

`-ConfirmReset` предназначен для заранее подтверждённых автоматических тестов/запусков командной строки; обычное окно всё равно требует подтверждение. Пользовательские регистрации Windows меняются только для стандартного профиля. Синтетические проверки используют отдельные профили, не трогая общую регистрацию. Блокировка профиля определяется именованным mutex, а не устаревшим номером PID.
