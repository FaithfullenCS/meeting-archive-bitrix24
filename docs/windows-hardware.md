# Оборудование Windows — Meeting Archive 0.2.5

Состояние на 04.10.2026. Проверка правил выбора библиотек на искусственных конфигурациях не заменяет запуск на каждом физическом компьютере.

| Система | Архив, Bitrix24, импорт | Локальная расшифровка |
|---|---|---|
| Windows 10/11 x64, Intel CPU | Основная сборка | CPU; GPU NVIDIA при совместимом драйвере |
| Windows 10/11 x64, AMD CPU | Та же основная сборка | CPU; GPU NVIDIA при совместимом драйвере. Процессор AMD не требует другого PyTorch |
| Windows x64, AMD Radeon / Intel GPU | Та же основная сборка | CPU. Ускорение на этих GPU в текущей сборке не подключено |
| Windows 11 ARM64 | Возможен запуск x64-приложения через эмуляцию Windows; на реальном ARM-компьютере здесь не проверено | Автоматическая установка остановлена. Нативной ARM-сборки и полного проверенного комплекта библиотек пока нет |
| Windows 10 ARM | x64-эмуляция не поддерживается Windows | Текущая сборка не поддерживается |

CPU-режим выбирается и подтверждается в **Настройки → Расшифровка на компьютере → Обработка → CPU**. Установка CPU-профиля использует CPU-библиотеки, без CUDA. Конкретный процессор должен поддерживать инструкции выбранного движка; для готовых x64-библиотек CTranslate2 требуется как минимум SSE 4.1. AMD CPU поддерживается CTranslate2 через oneDNN; встроенная видеокарта и NPU от этого не начинают использоваться.

## Как выбирается комплект NVIDIA

Выбирается профиль GPU NVIDIA, а приложение читает архитектуру карты (compute capability) и версию установленного драйвера. Наименование карты, настольный/мобильный корпус и оборудование разработчика не участвуют в выборе. Общий комплект PyTorch 2.7.1 / torchaudio 2.7.1 закреплён файлами с SHA-256:

| Архитектура GPU | Комплект для новой общей среды | Политика проверки драйвера Windows |
|---|---|---|
| Compute capability 5.x–9.x | CUDA 12.6, worker-cuda126.lock | 560.76 или новее |
| Compute capability от 10.0 до 12.0 включительно, включая Blackwell | CUDA 12.8, worker-cuda.lock | 570.65 или новее |
| Неизвестная/другая архитектура, NVIDIA не обнаружена | Загрузка не начинается | Понятное предложение обновить драйвер либо явно выбрать CPU |

Это консервативная политика приложения по версиям драйверов CUDA Toolkit GA, а не утверждение, что любой более старый драйвер принципиально не работает в режиме minor compatibility. Установщик драйвер не обновляет, CUDA Toolkit отдельно не требует. Совместимая найденная среда Whisper используется напрямую; её библиотеки не обновляются и не копируются.

До скачивания весов CUDA-профиль общей среды проходит реальное создание тензора, вычисление и синхронизацию GPU. Точное совпадение строки `sm_*` не требуется: совместимые cubin/PTX могут работать на другой минорной архитектуре. Если выполнение не проходит, веса не скачиваются, скрытого перехода на CPU нет. После переноса на другой компьютер уже установленная собственная среда проверяется повторно; неподходящая среда готовится по новому выбору.

Parakeet использует отдельный закреплённый нативный runtime NeMo-Speech.cpp CPU/CUDA, а не этот PyTorch. Его доступность проверяется командой doctor. Реальный запуск конкретной модели любого движка проверяется в настройках на 30 секундах сохранённой записи. Тест подтверждает запуск и скорость с текущими параметрами, но не гарантирует точность речи, достаточную память для любой длительности и работу на всех GPU.

## Ошибка загрузки Python.Runtime.dll после распаковки

Сообщение `Failed to resolve Python.Runtime.Loader.Initialize` возникает при загрузке .NET-библиотеки окна. Оно само по себе не означает отсутствие системного Python: Python базового приложения входит в ZIP. Возможные причины — блокировка скачанной DLL Windows, неполная распаковка или несовместимая среда .NET Framework.

Для блокировки Windows проверен воспроизводимый сценарий: интернет-метка `Zone.Identifier` на неизменённой `Python.Runtime.dll` вызывает именно это сообщение; удаление метки позволяет загрузить ту же DLL. Перед распаковкой официального ZIP откройте **Свойства → Разблокировать → Применить**. Если ZIP уже распакован, извлеките разблокированный ZIP заново в отдельную локальную папку и запустите EXE. Не заменяйте папки с личными записями и профилем.

Начиная с 0.2.28 приложение автоматически подготавливает четыре штатные .NET DLL: сначала проверяет их SHA-256 по `update-manifest.json`, затем снимает их интернет-метки. При несовпадении хешей или неполном комплекте предлагается повторная распаковка. В папке без разрешения на запись нужно разблокировать исходный ZIP и распаковать его заново в доступную локальную папку.

Microsoft описывает [блокировку локальной сборки, скачанной из интернета](https://learn.microsoft.com/en-us/dotnet/framework/configure-apps/file-schema/runtime/loadfromremotesources-element) и [снятие метки через Unblock-File](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/unblock-file). Источники официальные, проверены 06.10.2026.

## Почему Windows ARM пока отдельно

Сборка EXE, управляемый Python и закреплённые Windows-пакеты сейчас x64. На ARM приложение определяет архитектуру хоста через IsWow64Process2, даже когда процесс эмулируется как x64. Наличие ARM-поддержки у CTranslate2 в целом не означает наличие готовых Windows ARM wheels для всей этой цепочки. Для нативной поддержки нужны отдельная упаковка Python/EXE, подходящие FFmpeg и библиотеки всех предлагаемых движков, а затем реальные CPU-прогоны. Обычные функции архива в Windows 11 ARM можно проверить отдельно через эмуляцию x64; этот результат не следует объявлять проверкой ASR.

## AMD GPU

AMD уже публикует поддержку PyTorch/ROCm на Windows 11 для определённых Radeon и Ryzen. Это не универсальная поддержка всех AMD GPU и не функциональность текущего Meeting Archive. Здесь закреплены CPU/CUDA-комплекты и конкретные обработчики Whisper, Parakeet, GigaAM. Простая подмена torch на ROCm не включает AMD-ускорение у готовой Windows-библиотеки faster-whisper/CTranslate2 или нативного Parakeet. Такой режим потребует отдельного проверенного комплекта и интеграции движков; текущий интерфейс показывает фактически обнаруженный AMD-адаптер и предлагает CPU.
